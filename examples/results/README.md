# Experimental Results

This directory contains selected reproducible evaluation artifacts.

The following types of outputs were generated during the study:

- Facial expression editing examples
- AU-based expression grids
- Identity similarity evaluation
- Edited video frames
- Original-vs-edited video comparison
- Frame-level quantitative statistics



## Video experiment

A short video-processing experiment was conducted as an extension of
the image-based MagicFace inference pipeline.

The experiment:
1. extracts selected frames from a user-provided video,
2. applies MagicFace expression editing frame-by-frame,
3. reconstructs an edited video,
4. compares original and edited frames using basic pixel statistics.

The source video and generated video outputs are not included in this
repository because the source video is privately owned and cannot be
redistributed.

The complete processing workflow is documented in the notebook.

Selected results can be made available for research inspection (viewing only)
upon request.
